# Jio Platforms Limited RAN Simulator — Design v7

This package is a clean static UI prototype for the browser-owned simulator workflow.

## Pages
- Home: mode-first same-flow architecture
- Scenario / Geometry / Waveform / Traffic / MAC
- L1 / PHY explorer grouped by signal families
- Block Studio
- Real-Time Data
- Analytics
- Artifact Explorer
- Parameter Catalog
- Compare Runs

## Notes
- This is a static design prototype, not yet wired to your real backend or MySQL queries.
- The design is intended to be simple, clean, detailed, and easy to understand.
- Open `index.html` to start.
