2 Introduction 
 Purpose and Scope 
The purpose of this document is to provide an algorithm to estimate precoder for UL. gNB will 
estimate the optimum Rank and TPMI such that UE will use the same for UL data transmission.  
 Definitions, Acronyms, and Abbreviations 
The definitions, acronyms, and abbreviations used in this document are:

Signal-to-Interference-plus-Noise ratio 
 
Channel decomposition: To maximize the channel throughput, the channel must be 
diagonalized via the channel decomposition (e.g., singular value decomposition (SVD)). 
MIMO channel is decomposed to a set of parallel, independent scalar gaussian sub 
channels to achieve spatial multiplexing.
