3 RRM and OAM configurations 
a) Active User Set: A list of users whose buffer occupancy is non-zero is considered. Each user 
may have more than one service traffic. For instance, a user with VoNR traffic can also have 
GBR or Non-GBR traffic.  
b) The maximum number of users to be scheduled for each service queue for both UL/DL per 
slot is a RRM configurable parameter.  
1. maxRetxUsersPerSlot 
2. maxSRBUsersPerSlot 
3. maxVoNRUsersPerSlot 
4. maxGBRUsersPerSlot 
5. maxNonGBRUsersPerSlot  
c) The maximum number of DL/UL MU-MIMO layers per slot is defined. 
d) The maximum number of DL/UL SU-MIMO layers per slot is defined.  
e) RB allocation for GBR and Non-GBR Candidates (Three approaches can be considered) 
1. Static Allocation: In this approach we would define a max. number of RBs for each 
service per user. 
2. OnDemand Allocation: In this approach there is no restriction on number of RBs 
allocated per service or per UE.  
3. Alternatively, we could proportionally allocate RBs for the defined number of 
UEs/TTI

6 Sum rate maximization 
After selecting the mutually orthogonal set of users and ports, to satisfy the condition that only max 8 layers 
in MU-MIMO is supported, we need to select the subset of users among the mutually orthogonal users. The 
users can be selected based on the following. 
1. QOS order 
a. The users in top of the QOS priority list will be selected 
2. Orthogonality metric 
a. Among the mutually orthogonal users, the users with low correlation metric corresponding to 
the HOL user will be selected 
3. SINR 
a. For the different combinations of users, SINR is derived. The combination of users for which 
SINR is higher should be selected. This approach needs precoder at L2.

7 Effective MCS determination 
In case of SU-MIMO, the CQI reported by UE is used for MCS selection. But in case of MU-MIMO, as inter 
user interference comes into picture, the CQI reported by the user will not be accurate. Hence some offset 
must be induced in the reported CQI based on inter user interference. Two approaches are proposed below 
briefly. 
1. Give some offset to the reported CQI based on the number of MU-MIMO users paired 
2. Calculated the effective SINR considering the inter user interference and map the SINR to 
corresponding CQI  
a. For this approach, precoder is required at L2 
The detailed algorithm is yet to be discussed and analyzed.
