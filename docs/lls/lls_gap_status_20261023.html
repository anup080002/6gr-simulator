1–2. What is a port, a layer, a waveform chain and an antenna element?

A CSI-RS logical port identifies a reference signal and its effective channel. A data layer carries one spatial data stream. A waveform column is one sample stream presented to the configured channel/RF owner. A physical element belongs to the array model. Counts can differ: 64 configured transmit dimensions do not demonstrate rank-4 data, and four CSI ports do not prove four independent received data layers.

prepareCSIRSTransmission.m binds the actual carrier time and checks csirsOccasion.m. It calls materializeCSIRSPhysicalGrid.m, which obtains the reference symbols and maps each resource using its own matrix. The important normalized-runtime fields are phy.csirs.precoderMatrices, channel.nTxAnt, the carrier dimensions and the CSI period/offset. These are runtime fields, not a promise that arbitrary YAML spellings are accepted.

Actual implementation guards: the projection Gram residual must not exceed 1e-10; relative precoder reconstruction residual must not exceed 1e-9. These are numerical implementation checks, not 3GPP RF accuracy limits. The mapper validates finite unit-norm precoder columns and rejects collisions between emitted CSI resources. Unit column norms alone do not establish total-power conservation for arbitrary correlated simultaneous signals: inspect the actual sum, covariance and applied power scale.

Strict operation rejects a missing physical precoder. A legacy non-strict identity branch exists only for one resource with equal logical/waveform dimensions and is explicitly labeled in source; it is not substituted for a configured strict beam mapping. AntennaArrayFactory.m supplies the installed element/port architecture when dimensions differ. buildCSIRSPortReferenceInputs.m retains the original per-resource columns and pilot identity for later model scoring; it does not invent a new beam.

3–4. OFDM, CP, physical units, RF and the channel

ofdmModulate.m delegates this producer to CanonicalOFDMModulator.m and its native nrOFDMModulate path. The recorded OFDM receipt—not bandwidth alone—defines NFFT, sample rate, CP lengths, windowing, grid shape and exact waveform identity.

Conceptual useful OFDM symbol:
x_c[n] = aFFT Σ_k G[k,l,c] exp(j 2π k n / NFFT)
CP = copy of that symbol's configured trailing samples
Fs = NFFT × Δf   for the recorded native, unresampled path
Ncapture = Σ_l (NFFT + NCP,l), for the supported zero-windowing reference path

Original pre-RF transmit samples = original OFDM samples × AmplitudeScale
Per-chain sample power = mean_n |x_c[n]|²

aFFT denotes the actual modulator's normalization; do not assume the separate unitary helper's scaling applies to this native path. applyPowerContext.m owns the original amplitude scale and declares normalized_complex_baseband versus sqrt_mW. Only the latter makes squared sample amplitude a milliwatt quantity at that declared plane. 10 log10(P_mW) is dBm; normalized squared amplitude must not be relabeled dBm. RE power also requires the recorded waveform-to-grid scaling; time-sample power and occupied-RE power are not interchangeable.

queueSharedPeriodicCSIRS.m queues the actual contributor. CoupledWaveformStream.m and SharedWaveformPhysicalRuntime.m own continuous execution; RFImpairmentStream.m owns RF state. AppliedTXLinearReferenceStream.m and AppliedChannelReferenceStream.m retain the installed model operators for the audit. They must not replace the original practical receive samples.

The port-reference helper currently accepts a recorded native, unresampled, zero-windowing operator and validates CP/sample dimensions and original hashes. This is an explicit supported audit subset, not proof that other OFDM branches are wrong or already qualified. A nonlinear PA prevents a unique decomposition into independent physical port powers; the fixed-linear model and its residual must remain separate. Conducted power, radiated TRP and directional EIRP require their own array/reference-plane contracts; no antenna gain is automatically added here.

5 and 7. Exact receiver / feedback order and why report computation is not adaptation

completeSharedCSIRSReception.m executes the following order. This ordering is important: reference measurements cannot improve the receiver that they are supposed to assess.

  1. Obtain the original observation and its pre/post-front-end sample planes; call receiveCSIRSWaveform.m for practical reception.
  2. Bind the measurement plane using bindSharedCSIRSMeasurementPlane.m. Keep the original capture, timing/CFO operation, FFT support and receive-column identity.
  3. Call computeCSIRSFeedback.m to calculate the UE's report from the practical channel/measurement evidence.
  4. Bind the trial to the owner, received-sample identity, RF intervals and clocks; retain original evidence as configured.
  5. Run the separate isolated-component and multiport model scorers after reception/report calculation.
  6. Export retained estimation/selection evidence and apply the CSI trial to state. Later UCI transmission, decoding, report admission, grant freezing and actual data application require their own evidence.

NRCSIReportEngine.m and selectNRMaxSEWithEvidence.m retain actual selection operands. For the inspected MATLAB MaxSE policy, the rank objective is Σ_codeword L_c × (1 − modelBLER_c) × SE(CQI_c). This is a model-estimated selection policy, not decoded BLER or proof of independently optimal RI/PMI. Recommended RI, decoded RI, admitted rank and transmitted layers are distinct fields. A beam identifier is not a PMI; an applied explicit matrix can have no scalar PMI representation.

A positive CSI result alone cannot close a link-adaptation defect. Required causal chain: original measurement → generated report bits → received UCI → accepted report timestamp → selected grant MCS/rank/precoder → actual PDSCH/PUSCH decode. The newest bounded test below verifies the first/report-computation part, not that entire chain.

6. Original CDM power and CSI-IM: full calculation and a worked example

Practical estimatormeasureCSIRSCDMPortPower.m despreads each complete original CDM tile for port 3000. It does not coherently average one channel coefficient across a frequency-selective band. The associated measureCSIIM.m supplies the received disturbance second moment on separately configured CSI-IM REs.

For tile g, branch b and original pilot vector p_g:
E_g = Σ_i |p_g[i]|²
w_g = conj(p_g) / E_g
c_g,b = transpose(w_g) × Y_g,b     (NON-conjugating transpose)
Npilot = total port-3000 pilot RE count
Q_b(Y) = Σ_g E_g |c_g,b|² / Npilot
β = Σ_g E_g Σ_i |w_g[i]|² / Npilot
D_IM,b = original received CSI-IM second moment on its own RE support
P̂_b = Q_b(Y) − β D_IM,b           (signed; no nonnegative clipping)

Illustration ONLY, not a run measurement:
p = [1,1], Y = [2,2], E = 2, w = [0.5,0.5]
c = 2, Q = 4, β = 0.5, D_IM = 0.1
P̂ = 4 − 0.5 × 0.1 = 3.95; P̂ / D_IM = 39.5 ≈ 15.97 dB

The bias model assumes locally uncorrelated disturbance. CDM pilot orthogonality does not guarantee perfect isolation when the effective channel changes inside a tile. An unbiased linear-power estimate also does not make its logarithm, ratio or selected maximum unbiased. Negative signed estimates remain visible; a positive logarithm is not invented for them.

The original CDMProjectionReceipt retains tile indices, complex weights/coefficients as real and imaginary arrays, energies, original sequential accumulation, pilot count, carrier clock, receive columns and support hashes. measureCSISINRFromResourceGrid.m propagates this evidence. A grid-only receipt does not by itself establish physical waveform units or original shared-owner identity; those are bound and checked by the integrated scorer.

Independent audit branch: same operator, all cross terms, no perfect-feedback shortcut

Declared fixed-linear modelscoreSharedCSIRSLinearPortModel.m and compareCSIRSCDMModelReference.m compare against the original installed model using the same recorded receiver timing/CFO/FFT and original CDM weights. They do not redraw noise, reacquire timing, rerun the practical receiver or change report bits.

Y = original received pre-front-end grid
D = actual original serving-link contribution
A = original installed fixed-first-order aggregate model
T = target resource's port-3000 fixed-linear component
O = A − T; R = D − A; X = Y − D
Y = T + O + R + X

Apply the original c_g(·) and Q(·) to every component:
Q(Y) = Q(T) + Q(O) + Q(R) + Q(X)
       + 2 Re{⟨T,O⟩ + ⟨T,R⟩ + ⟨T,X⟩ + ⟨O,R⟩ + ⟨O,X⟩ + ⟨R,X⟩}
⟨U,V⟩ = Σ_g E_g conj(c_g(U)) c_g(V) / Npilot

Practical numerator: Q(Y) − β D_IM
Model numerator:     Q(T)
Both diagnostic ratios use the SAME original D_IM.

O includes all other linear contributions, not only other CSI ports. R includes DAC/other model discrepancy, not only PA distortion. X includes other received links and original noise. All six signed cross terms are necessary: component powers alone need not sum to composite power.

Critical boundary: DenominatorIndependentlyReferenced=false. Matching the CDM operator repairs an invalid comparison, but the shared observed CSI-IM denominator is not an independent interference/noise truth reference. The result is an operator-matched model diagnostic, not standardized physical SINR accuracy. Target leakage on CSI-IM remains separately recorded, not silently removed. Raw target-RE power and CDM-projected target power are both retained; their difference exposes intra-tile projection loss.

The arithmetic closure guard uses a floating-point forward-error bound based on original absolute operands: u=eps(double)/2, k=16N+64, γ=k·u/(1−k·u). It is not a radio tolerance. This avoids rejecting valid near-cancellation while still rejecting materially corrupted components. Zero model power yields −∞; undefined ratios/differences stay undefined. No native no-CSI-IM residual estimate is declared matched merely because its number is close.

Reference mathematics: absolute samples without forcing measured SINR

3GPP model UMa large-scale path loss and CDL-C small-scale fading use separately declared assumptions from TR 38.901 V18.0.0, §7.4.1 and §7.7.1. Combining them does not mean that each CDL path has its own measured macro path loss. Implementation policy The six target values, nominal reference geometry and noise-setting procedure are this experiment's choices, not mandated 3GPP values.

K = 12 × reference BWP PRBs
P_ref [mW per reference RE] = (P_nominal,total [mW] / K) × 10^(−PL_reference/10)
γ_reference = 10^(target_EsN0_dB/10)
N0 [mW/Hz] = P_ref / (reference subcarrier spacing [Hz] × γ_reference)
σ²_complex_sample [mW] = N0 × executed sample rate [Hz]
n = sqrt(σ²/2) × (u + jv), with independent unit-variance Gaussian u,v

For native unnormalized FFT and Fs = Nfft × Δf:
E{|FFT(n)|²} = Nfft × σ²
Physical RE noise power = E{|FFT(n)/Nfft|²} = N0 × Δf.

The nominal reference excludes instantaneous fading, selected beam gain, rank gain, PA loss and actual allocation-dependent UL power control. Those effects remain in the executed signal and can move measured SINR away from the nominal target. Noise must not be recalculated from a faded capture, successful decoding, current rank or the receiver's estimated path loss. A configured reference is not an oracle supplied to the practical estimator.

This is controlled absolute-noise LLS, not a claim that a real receiver has the corresponding noise figure. The separate physical thermal-noise baseline retains its declared receiver noise figure and PSD; it cannot simultaneously guarantee arbitrary measured SINR targets. The new mode must preserve absolute sqrt(mW) samples, UMa attenuation and UL power-control operation, and retain its exact reference operands in the run configuration and noise receipts.

Multiport power comparison: why the nonlinear residual and cross terms must remain visible

Implementation policy, not a new 3GPP measurement definition. The original received pre-front-end samples are Y. The original serving-link contribution is D, its installed fixed-first-order reference is A, and one resource's port-3000 reference is T. The remaining linear contribution is O=A−T; the actual-versus-model discrepancy is R=D−A; other received contributions are X=Y−D. Thus Y=T+O+R+X. O can include common transmitter components and other signals, not just another CSI port. R can include DAC and other model differences, not just PA distortion.

Every term must use the same original capture, receiver columns, recorded timing/CFO operator and FFT/resource support. Power closure is mean(|Y|²)=Σ mean(|Zi|²)+2Σi<j Re(mean(conj(Zi)Zj)), with Zi∈{T,O,R,X}. Omitting the signed cross terms can create an incorrect power budget. A comparison with T measures error relative to that declared model; it does not establish a unique physical per-port decomposition after a nonlinear PA. Neither an exact algebraic closure nor a passing CSV test establishes statistical RSRP/SINR accuracy.
